# Fotografias de produto — SINAGEPE

Coloque nesta pasta (`assets/img/produtos/`) as fotografias reais. O sistema
procura primeiro a fotografia; se o ficheiro não existir, entra automaticamente
a ilustração vectorial. Não é preciso tocar em código.

## Nomes de ficheiro obrigatórios

| Produto no sistema | Ficheiro |
|---|---|
| Arroz | `arroz.jpg` |
| Trigo | `trigo.jpg` |
| Farinha de Milho | `farinha-milho.jpg` |
| Óleo Alimentar | `oleo-alimentar.jpg` |
| Açúcar | `acucar.jpg` |
| Feijão | `feijao.jpg` |
| Fertilizantes | `fertilizantes.jpg` |
| Medicamentos | `medicamentos.jpg` |
| Cimento Nacional | `cimento.jpg` |
| Gasóleo (Diesel) | `gasoleo.jpg` |
| Gasolina | `gasolina.jpg` |
| Jet A-1 | `jet.jpg` |
| Gás de cozinha (GPL) | `gpl.jpg` |

Formato recomendado: JPEG quadrado, 600×600 px, abaixo de 150 KB.
Enquadramento apertado no produto, fundo escuro ou neutro — as imagens aparecem
sobre fundo `#0C1626` e fotografias de fundo branco destoam.

## Licenciamento — leia antes de descarregar

Este é um sistema do Estado. Uma fotografia usada sem direitos é um problema
jurídico e de reputação, não um detalhe técnico. Três vias aceitáveis:

**1. Fotografia própria (preferível).** Fotografe os armazéns, os terminais e os
produtos reais. Além de resolver a licença, mostra Moçambique em vez de imagens
genéricas — e isso nota-se numa apresentação oficial.

**2. Wikimedia Commons.** Repositório de imagens com licença livre.
Procure em https://commons.wikimedia.org por: `rice sack`, `wheat grain`,
`maize flour`, `cooking oil bottle`, `cement bag`, `diesel pump`, `petrol pump`,
`fertilizer bag`, `LPG cylinder`. Confirme sempre a licença de **cada** imagem:
- Domínio público ou CC0 — uso livre, sem obrigações.
- CC BY ou CC BY-SA — uso livre **com atribuição obrigatória**. Registe o crédito
  em `CREDITOS.md` (modelo abaixo).

**3. Bancos de imagem comerciais.** Se comprar licença, guarde o comprovativo.

Não use imagens encontradas em pesquisas de imagens genéricas nem fotografias de
marcas comerciais identificáveis: rótulos de marca em imagens oficiais do Estado
levantam questões de favorecimento.

## Modelo de CREDITOS.md

```
# Créditos das imagens

## arroz.jpg
- Fonte: Wikimedia Commons
- URL: <endereço da página da imagem>
- Autor: <nome>
- Licença: CC BY-SA 4.0
- Data de obtenção: <data>
```

Mantenha este registo actualizado. Numa auditoria, a pergunta "de onde veio esta
imagem" tem de ter resposta em segundos.
